Geeta Store Analysis 2022 | Excel Dashboard

📌 Project Overview
An Excel-based data analytics project analyzing Geeta Store's 2022 clothing sales data sourced from Kaggle. The goal was to identify sales trends, understand customer purchasing patterns, and derive meaningful business insights through an interactive dashboard.

🛠️ Tools & Skills
- **Microsoft Excel**
- Data Cleaning and Preparation
- Calculated Columns
- Pivot Tables and Charts
- Data Visualization
- Interactive Filters and Slicers

🔍 Key Business Questions
- Which month recorded the highest sales and orders?
- Which gender contributed more to sales?
- What was the distribution of order statuses?
- Which were the top 10 states by sales?
- How did sales vary across age groups and genders?
- Which sales channel and product categories performed best?

📈 Key Insights
- **Gender:** Women contributed 64% of sales, compared to 36% from men.
- **Monthly Trend:** March recorded the highest sales and order volume.
- **Sales Channel:** Amazon was the leading sales channel.
- **Top State:** Maharashtra ranked highest in sales.
- **Product Categories:** Set and Kurta were among the leading categories.

⚙️ Project Workflow
1. Cleaned and prepared the raw dataset.
2. Created additional columns for meaningful analysis.
3. Used Pivot Tables to summarize sales data.
4. Created charts to visualize trends and comparisons.
5. Built an interactive dashboard using filters and slicers.
